🚀 ULTIMATE WEBSITE PERFORMANCE OPTIMIZATION PROMPT (with WebP/AVIF Conversion)

Goal:
Optimize my Django + React + Nginx website for speed, especially for slow-loading hero images and overall lagginess.
Focus on Core Web Vitals (LCP, INP, CLS), image optimization, and best practices for 2024–2025.

---

1. Image Optimization (Hero & All Images)

- Automatically convert all images uploaded by admins to WebP (and AVIF if possible) on the backend.
  - Store the original image as a fallback.
  - Update the frontend to use <picture> with WebP/AVIF sources and a JPEG/PNG fallback.
  - If there is a strong reason not to do this (e.g., compatibility, quality loss), document it and suggest the best alternative.
- Generate multiple sizes for each image (e.g., 400w, 800w, 1200w, 2000w).
- Update frontend code to use:
  - <picture> and <img> with srcset and sizes for responsive images.
  - Example:
    <picture>
      <source srcSet="/media/hero.avif" type="image/avif" />
      <source srcSet="/media/hero.webp" type="image/webp" />
      <img
        src="/media/hero-800w.jpg"
        srcSet="/media/hero-400w.jpg 400w, /media/hero-800w.jpg 800w, /media/hero-1200w.jpg 1200w"
        sizes="(max-width: 600px) 100vw, 800px"
        alt="Hero"
        width="800"
        height="400"
      />
    </picture>
- Preload the hero image in the HTML <head>:
  <link rel="preload" as="image" href="/media/hero-800w.jpg" imagesrcset="/media/hero-400w.jpg 400w, /media/hero-800w.jpg 800w, /media/hero-1200w.jpg 1200w" />
- Do NOT lazy-load above-the-fold images (remove loading="lazy" from hero/critical images).
- Compress all images using tools like Squoosh, TinyPNG, or ImageMagick.

---

2. Nginx & CDN Optimization

- Enable Gzip and Brotli compression for static assets in Nginx.
- Set long cache headers for static and media files:
  location ~* \.(jpg|jpeg|png|webp|avif|gif|ico|css|js)$ {
      expires 30d;
      add_header Cache-Control "public, no-transform";
  }
- Serve static and media files via a CDN (Cloudflare, BunnyCDN, etc.) if not already done.

---

3. React & Frontend Optimization

- Implement code splitting and lazy loading for non-critical React components.
- Minify and compress all JS and CSS bundles.
- Inline critical CSS for above-the-fold content.
- Defer or async-load non-critical JS.

---

4. Django Backend Optimization

- Ensure Redis caching is active for Django views and static/media if possible.
- Optimize database queries for API endpoints used on the homepage/hero section.
- Use Django’s cache middleware for public pages if not already enabled.

---

5. General Best Practices

- Audit for oversized images: No image should be more than 1.5x its display size.
- Use next-gen formats everywhere possible.
- Reserve space for images using width/height attributes to prevent layout shift (CLS).
- Remove unused JS/CSS from the build.
- Test with Google PageSpeed Insights and WebPageTest after changes.

---

6. Testing & Monitoring

- Run Google PageSpeed Insights and WebPageTest before and after changes.
- Aim for:
  - LCP < 2.5s
  - INP < 200ms
  - CLS < 0.1
